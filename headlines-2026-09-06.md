**Selection window:** 2026-09-05 13:36 UTC to 2026-09-06 13:36 UTC (24 hours), filtered by each item's original publication timestamp (each outlet's own RSS `<pubDate>` for WSJ/NYT/NBC; for AP, the original publication time attached to the underlying AP article as cross-verified against AP's own site, not Google's feed-retrieval time).

**Access notes:**
- All eight listed WSJ feeds, all ten listed NYT feeds, and all eight listed NBC feeds were fetched directly with the specified user agent and parsed successfully as RSS/XML. No feed was inaccessible.
- The specified Google News search (`site:apnews.com when:1d`) was fetched directly and returned 100 candidate items with real headlines and timestamps, so it worked for candidate discovery and time-filtering. However, its `<link>` values are Google redirect tokens (`news.google.com/rss/articles/...`) that resolve only inside a JavaScript-rendered interstitial — following HTTP redirects returns a self-referential 302, so they could not be converted into canonical `apnews.com` URLs mechanically. For each of the five AP finalists, the exact headline text was instead cross-verified against AP's own site search (`apnews.com/search?q=...`, directly fetchable), matching the precise headline string to its canonical `apnews.com/article/...` URL; all five were confirmed to return HTTP 200.
- WSJ and NYT article pages themselves were not fetched directly (both gate unauthenticated requests behind paywall/bot checks); all five WSJ and five NYT links are canonical URLs taken directly from each outlet's own RSS feeds, with tracking query parameters stripped. All five NBC links were verified to return HTTP 200.

A second cross-outlet thread was the U.S.-brokered Ukraine peace push, with envoys Witkoff and Kushner meeting Putin in Moscow and then making a first visit to Kyiv, also picked up by all four outlets.
