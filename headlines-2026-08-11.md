## Note

Selection window: 2026-08-10T13:56 UTC through 2026-08-11T13:56 UTC (09:56 ET to 09:56 ET). All eight WSJ Dow Jones RSS feeds, all ten NYT section RSS feeds, all eight NBC section RSS feeds, and the AP-focused Google News search feed listed in the source instructions returned HTTP 200 via direct fetch and were used to build each outlet's initial candidate pool (364 raw / 89 in-window for WSJ; 327 raw / 156 in-window for NYT; 185 raw / 66 in-window for NBC; 100 raw / 100 in-window for the AP-focused Google News feed); items were filtered on each item's own publication timestamp (RSS `pubDate`), not on feed-retrieval time.

Two access limitations affected sourcing, both consistent with this repository's established practice. First, apnews.com has no general-news RSS feed and its `/*.rss` paths are disallowed by robots.txt, so the Google News `site:apnews.com when:1d` search feed was used for discovery only (its redirect links resolve solely via client-side JavaScript that a plain HTTP fetch cannot execute); AP's candidate pool of canonical URLs was instead built by directly fetching apnews.com's homepage and its world-news, us-news, politics, business, technology, science, and health topic pages (robots.txt permits direct fetch for a generic user agent, only disallowing the `ClaudeBot`/`CCBot` crawlers by name), extracting headline text and canonical `apnews.com/article/...` links from the server-rendered HTML, then matching each candidate against the Google-News-derived title/time list and verifying `datePublished`/`dateModified` via each article page's own embedded JSON-LD metadata before selection. This is a direct-fetch substitution, not a fabricated or guessed URL. One AP selection (the Colombia earthquake) is a live-updating rolling story whose page-level `datePublished` (2026-08-10T13:09 UTC) sits 47 minutes before this window's start; the specific "3,000 missing" URL selected instead carries its own `datePublished` of 2026-08-11T04:24 UTC, squarely in-window, and was used for that reason. Second, wsj.com and nytimes.com article pages returned 401/403 bot-detection errors on direct fetch, so WSJ and NYT selections rely on each outlet's own RSS `title`/`link`/`pubDate` fields, used verbatim, consistent with prior digests. One NBC selection (Trump's decoy-plane departure from Turkey) exists in NBC's own reporting only as a today.com video segment, not a text article; nbcnews.com's politics and national-security sections were checked directly and returned no separate text version, so the today.com (NBCUniversal-owned) URL is used as the canonical link for that item.
