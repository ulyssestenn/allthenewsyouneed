## Note

Selection window: 2026-08-08T13:36 UTC through 2026-08-09T13:36 UTC (09:36 ET to 09:36 ET). All eight WSJ Dow Jones RSS feeds, all ten NYT section RSS feeds, all eight NBC section RSS feeds, and the AP-focused Google News search feed listed in the source instructions returned HTTP 200 via direct fetch and were used to build each outlet's candidate pool (364, 298, 186, and 100 raw items respectively); items were filtered on each item's own `pubDate`, not on feed-retrieval time, leaving 18 WSJ, 51 NYT, 15 NBC, and 100 AP in-window candidates after deduplication by canonical URL.

Two access limitations affected sourcing. First, apnews.com's robots.txt explicitly disallows Claude-affiliated crawlers (`ClaudeBot`, `anthropic-ai`) and its RSS endpoints (`/*.rss`), so it was not fetched directly; AP has no general-news RSS feed, so its 100-item candidate pool came from Google News's `site:apnews.com when:1d` search feed. Google News's redirect links resolve only via client-side JavaScript that a plain HTTP fetch cannot execute, and roughly 40% of that feed's entries were bare topic-page redirects (e.g., "Florida - AP News," "Baseball - AP News") rather than articles, so each was screened out before ranking. Consistent with this repository's established practice, all five AP headlines instead link to independent wire-copy mirrors (Anchorage Daily News, WFMZ Allentown, 2News Reno, and WRAL Raleigh), each confirmed via direct fetch to carry an explicit named or generic Associated Press byline (e.g., "By TY ONEIL and DORANY PINEDA — Associated Press"; "MUNIR AHMED"; "JOSH FUNK — AP Business Writer") matching the Google News-indexed headline and details. This is a deliberate substitution, not a fabricated or guessed URL. Second, wsj.com and nytimes.com article pages were not fetched directly this run (both return bot-detection errors on direct request), so WSJ and NYT selections rely on each outlet's own RSS `title`/`link`/`pubDate` fields, which were used verbatim.
